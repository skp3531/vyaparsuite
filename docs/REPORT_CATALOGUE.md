## 1. Reporting Architecture Overview

VyaparSuite’s reporting engine delivers high-density, real-time analytical capabilities with zero batch delays. Designed with PostgreSQL 16+ analytical features (window functions, CTEs, materialized rollups) and TanStack Table frontend virtualization, the system handles multi-million row datasets while maintaining sub-second query execution.

### 1.1 Report Classification Framework
- **Tabular**: High-density transaction logs with column filtering, sorting, and drill-down links.
- **Grouped**: Multi-level hierarchical aggregates (e.g., Parent Group -> Child Subgroup -> Leaf Voucher).
- **Summary**: Condensed period-over-period financial balances and executive rollups.
- **Pivot**: Dynamic multidimensional cross-tabulations (e.g., Month vs Category vs Revenue).
- **Chart / KPI**: Visual cockpit components with sparklines, bar funnels, and trend vectors.

### 1.2 Statutory & Security Compliance
- **Row Level Security (RLS)**: Enforced unconditionally at the database layer; reports automatically scope to the user's active tenant, authorized company, and assigned branches.
- **Field-Level Masking**: Sensitive figures (cost price, valuation, Aadhaar, salary components) are stripped or redacted unless the user holds elevated permissions.
- **Export Audit Log**: Every CSV, XLSX, and PDF export event is permanently recorded in the MCA Rule 3 compliance audit trail.
